Security & Privacy

P.C Quality Education Platform for Sierra Leone protects learners with safe access, role-based dashboards and two-step verification for teachers and admins.

🔐

Secure Login

Password fields, show/hide control, validation and protected role routing.

📲

Two-Step Verification

Required for teacher and admin accounts before they can upload content or control the system.

🛡️

Role-Based Access

Students, parents, teachers and admins each see the tools meant for their role.

👶

Child-Safe Platform

Moderation controls, abuse reporting and safe learning rules.

📄

Data Privacy

Only necessary information is requested. A real version would store passwords with hashing on a secure server.

📊

Security Logs

Admin can review failed logins, account approvals and platform changes.

Frontend Demo Security Check

This checks basic password strength and explains the security level. It is a project demo, not a real server scan.

User Rights

  • View and edit profile information.
  • Request account deletion.
  • Report unsafe content or abuse.
  • Use large text and dark/light mode for accessibility.
  • Know what information the platform collects.
